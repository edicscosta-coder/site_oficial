## 🌐 Como Integrar no seu Site (www.nexarus.com.br)

### Opção 1: No Odoo (onde o nexarus.com.br está hospedado)
1. Acesse o painel de administrador do **Odoo** no seu site.
2. Crie uma nova página (por exemplo, `/ingles-intensivo` ou `/matriculas` ou substitua a página principal de vendas).
3. Insira um bloco de código/snippet HTML ou copie o conteúdo de `standalone-sales-page.html`.
4. Salve e publique.

### Opção 2: Hospedagem Independente (Vercel / Netlify / Hostinger / etc.)
Se preferir criar um subdomínio como `aprender.nexarus.com.br` ou `lp.nexarus.com.br`:
1. Faça upload da pasta `nexarus-sales-page` no Vercel, Netlify ou qualquer serviço de hospedagem estática.
2. Conecte o subdomínio nas configurações de DNS.
